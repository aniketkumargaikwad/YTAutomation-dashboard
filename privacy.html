Privacy Policy

YTAutomation Uploader · Effective 23 November 2026

YTAutomation Uploader ("the app") is a private tool, run by its developer, that uploads the developer's own videos to the developer's own YouTube channels. This policy explains what data the app accesses and what it does with it.

1. Who the app is for

The app has one user: its developer. It has no public sign-up and does not ask anyone else to sign in or share data.

2. Data the app accesses

When the developer signs in with Google, the app receives OAuth access and refresh tokens for the developer's own YouTube channels. It uses the YouTube API Services with these scopes only:

  • https://www.googleapis.com/auth/youtube.upload: to upload videos and set video thumbnails.
  • https://www.googleapis.com/auth/youtube.readonly: to read the signed-in channel's ID and title, so the app can check it is uploading to the intended channel.

The app also reads public statistics (views, likes) of the videos it has published, to show them on the developer's dashboard.

3. How the data is used

  • Tokens are used only to upload the developer's videos, set their thumbnails and confirm the channel.
  • Video statistics are used only to show performance on the developer's dashboard.
  • The app does not use the data for advertising, profiling or any other purpose.

4. Storage and security

  • Refresh tokens are stored as encrypted secrets in the developer's private GitHub repository (GitHub Actions secrets) and in a local file on the developer's own computer.
  • Access tokens are kept in memory only for the duration of an upload run (under one hour) and are not saved.
  • Video IDs, titles and public statistics of published videos are stored in the developer's repository to run the schedule and dashboard.

5. Sharing

The app does not sell, rent or share any data with third parties. Data is sent only to Google (YouTube API Services) to perform the uploads.

6. Retention and deletion

Tokens are kept while the app is in use. Access can be revoked at any time from the Google security settings page. After revocation the stored tokens no longer work, and the developer deletes them from the repository secrets and the local file. Stored statistics can be deleted by the developer at any time.

Data obtained from YouTube API Services (video IDs and statistics) is refreshed at least every 30 days. Data that can no longer be refreshed, for example after access is revoked or a video is deleted, is deleted within 30 days.

7. YouTube and Google

The app uses YouTube API Services. By using the app you agree to the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

8. Changes

If this policy changes, the new version will be posted on this page with a new effective date.
